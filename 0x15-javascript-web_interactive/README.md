# 0x15. JavaScript - Web jQuery

This project contains JavaScript scripts that manipulate HTML elements using vanilla JavaScript.

## Tasks

- 0-script.js - Turn the header red
- 1-script.js - Change all paragraph text to blue
- 2-script.js - Turn the header red when clicked
- 3-script.js - Add a red class to the header when clicked
- 4-script.js - Toggle the header between red and green
- 5-script.js - Add a new list item when clicked
- 6-script.js - Change the header text when clicked
