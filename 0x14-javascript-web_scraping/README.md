# 0x14. JavaScript - Web scraping

This project contains JavaScript scripts that demonstrate web requests, file operations, and processing data from APIs using Node.js and the request module.

## Files

- 0-readme.js - Reads and prints the content of a file.
- 1-writeme.js - Writes a string to a file.
- 2-statuscode.js - Prints the HTTP status code of a request.
- 3-starwars_title.js - Prints the title of a Star Wars film.
- 4-starwars_count.js - Counts films featuring Wedge Antilles.
- 5-request_store.js - Fetches a webpage and stores the response in a file.
- 6-completed_tasks.js - Counts completed tasks by user ID.

## Requirements

- Node.js
- request module
- semistandard
